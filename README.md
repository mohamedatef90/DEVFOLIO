# DevFolio

A static, single-page personal portfolio website built with HTML, CSS, and Bootstrap 5. There is no JavaScript of its own and no build step.

## Sections of `index.html`

Home (intro), About, Services, an overview counters section, Work (portfolio of six images), testimonials, Blog, and Contact (a form).

## Tech

- HTML and CSS (`css/style.css`)
- Bootstrap 5 and Font Awesome, bundled in `css/` and `js/`
- Fonts from Google Fonts

## Running

Open `index.html` in a browser. Google Fonts need an internet connection; everything else is local.

## Project structure

```
index.html   The page
css/         Bootstrap, Font Awesome, and custom styles
js/          Bootstrap bundle
img/         Intro, counters, work, blog, and testimonial images
```
